# Mini Tetris

Un Tetris sencillo hecho con HTML, CSS y JavaScript. No necesita librerías ni instalación.

## Cómo probarlo
1. Descarga o descomprime esta carpeta.
2. Abre `index.html` con tu navegador.

## Cómo publicarlo con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` (o sube todos los archivos de esta carpeta).
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. GitHub te mostrará el enlace de tu página cuando termine de publicarla.

## Controles
- Flechas izquierda/derecha: mover.
- Flecha arriba: girar.
- Flecha abajo: bajar.
- Espacio: caída rápida.
- P: pausar.
- También hay botones táctiles para jugar desde el móvil.
